# Pixi - Game Store (Full Stack Web Application)
**Pixi** — istifadəçilərin oyunları kəşf edə, səbətə əlavə edə və idarə edə biləcəyi, eyni zamanda administratorların platformanı tam idarə etməsi üçün funksional Admin Panelə sahib olan müasir **Game Store (Oyun Mağazası)** veb saytıdır
Layihə lokal mühitdə (`localhost`) tam funksional vəziyyətdədir və Full Stack arxitektura əsasında qurulmuşdur

---

## Özəlliklər 

### İstifadəçi Paneli (User Side)
* **Autentifikasiya:** İstifadəçilərin qeydiyyatdan keçməsi (Register) və profil yaradaraq daxil olması (Login)/JWT token(self-study)
* **Oyun Kataloqu:** Populyar, endirimdə və pulsuz oyunların dinamik şəkildə siyahılanması və filterlənməsi
* **Səbət Sistemi (Cart):** Bəyənilən oyunların səbətə əlavə edilməsi, baxılması və idarə olunması
* **Kateqoriyalar:** Oyunların janrlarına və növlərinə görə qruplaşdırılması

### Admin Paneli (Management Side)
* **Oyunların İdarə Edilməsi:** Yeni oyunların əlavə edilməsi, silinməsi və məlumatlarının yenilənməsi (CRUD əməliyyatları)
* **Endirim Kampaniyaları:** Seçilmiş oyunlara xüsusi endirimlərin tətbiq edilməsi sistemi (oyunun köhnə dəyərini yenilədikdə (azaltdiqda) avtomatik faiz hesablanaraq endirimli oyun hesab olunur)
* **Kateqoriya Menecmenti:** Oyun kateqoriyalarının və janrlarının təşkili

---

## İstifadə Olunan Texnologiyalar (Tech Stack)
### Frontend
* **React.js** — Dinamik və sürətli istifadəçi interfeysi üçün (self-study)(frontend qovlugunda react yoxdur)
* **JavaScript (ES6+)** — Müştəri tərəfli məntiqlər və API sorğuları üçün
* **HTML5 & CSS3** — Struktur və vizual dizayn üçün 
* **Figma** — Layihənin UI/UX dizayn mərhələsi üçün (self-study)

### Backend & Verilənlər Bazası
* **C# .NET Core** — Güclü və təhlükəsiz backend arxitekturası üçün
* **Web API** — Frontend və Backend arasında problemsiz məlumat mübadiləsi üçün
* **SQL Server** — İstifadəçi, oyun və kateqoriya məlumatlarının strukturlaşdırılmış şəkildə saxlanılması üçün
